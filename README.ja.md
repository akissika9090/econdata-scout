# EconData Scout（日本語 README）

経済学の論文が**実際に使った主要データ**を、原文の引用とページ付きで示し、そのデータを**どこから・どんな条件で入手できるか**の手がかりを日本語の表にまとめるツールです。研究テーマを決める前に、「先行研究のデータを自分も使えるか」を確認する段階を想定しています。

英語版：[README.md](README.md)　｜　設計と評価：[docs/access_catalog_ja.md](docs/access_catalog_ja.md)　｜　概要：[docs/overview_ja.md](docs/overview_ja.md)

## 2 つの使い方（同じツールの 2 つの入口）

### 1. 論文を持っている場合：PDF をアップロード（主な使い方）

研究方向を指定せず、手元の論文 PDF だけを渡します。論文検索は行いません。

```bash
python scout.py --pdf paper1.pdf paper2.pdf
```

例：
```bash
python scout.py --pdf Vertical_integration_COVID.pdf
```
→ `runs/<日時>/` に次の 2 つが保存されます。
- `report.md`：論文が使ったデータ、原文の引用とページ、サンプル年、論文に書かれた入手条件（英語）
- `access_table_ja.md`：主要データごとの日本語の表（論文が使ったデータ／結論／入口／次にやること／未確認の条件）

```
| 論文 | 論文が使ったデータ | 結論 | 入口 | 次にやること | 未確認の条件 |
| … | CSMAR（…） | 🔐 契約が必要（範囲は要確認） | https://data.csmar.com/ | 大学図書館が CSMAR を契約しているか、必要なサブデータベースと年が範囲に入っているか確認する | 所属大学の契約状況と範囲 |
```

必要なキー：`GEMINI_API_KEY`（データ抽出）。

### 2. まだ論文がない場合：研究方向から始める

研究方向（英語）を入力すると、OpenAlex で候補論文を検索し、モデルが関連度を採点します。関連度が高く全文を無料で読める論文（3 本程度）を自動で調べ、全文を読めない関連論文はアップロード候補として一覧にします。

```bash
python scout.py "the effect of minimum wage on employment in China"
python scout.py "the effect of minimum wage on employment in China" --pdf paywalled_paper.pdf   # 自分で入手した論文を追加
```

**注意：候補論文の関連度はモデルの判断です。**報告の冒頭にある論文一覧を見て、本当に自分のテーマに関係するかを確認してください。関係のない論文が含まれていた場合、その論文のデータは無視するか、自分で選んだ論文を使い方 1 で調べ直してください。

必要なキー：`GEMINI_API_KEY`、`OPENALEX_API_KEY`（無料）。

### オプション（両方の使い方で共通）
- `--official`：データごとに提供機関の公式サイトを検索して現在の入手方法を確認する（`DEEPSEEK_API_KEY` が必要、有料）
- `--agent`：未確認のデータについて、論文本文を再検索するエージェントを動かす

## インストール

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
export GEMINI_API_KEY='…'      # キーは環境変数からだけ読み、ファイルには保存しません
```

Python 3.14（macOS）で動作確認。標準テストは Python 3.10（Linux）でも通過。

## 入手経路の表の読み方

入手の**制限**と、ツールが**確認できた段階**を分けて書きます。「機関の資格が必要」と分かること自体が、テーマを決める前の判断材料になるからです。

| 結論 | 意味 |
|---|---|
| ✅ 入手可能（確認済み） | 論文が使った版について、公開・登録で入手できる公式ページを確認済み |
| 🔐 制限付き入手（入口確認済み） | 申請・審査が必要。申請先と資格を確認済み（承認されるかは別問題） |
| ⛔ 入手制限あり（確認済み） | 公式に研究者向けの入手経路がない |
| 🔐 契約が必要（範囲は要確認） | 商用データベース。所属大学の契約範囲を図書館で確認する |
| ❓ この版の入手方法は未確認 | 製品の一般的な説明はあるが、論文が使った版・年に当てはまるか未確認 |
| 🔎 手がかりのみ／— カタログ未収録 | 製品を特定できない、またはカタログ（中国のデータ 9 種）にない |

## デモ（使い方 1）

[demo/outputs/access_table_ja.md](demo/outputs/access_table_ja.md)：China Economic Quarterly International 2022 年第 2 巻第 3・4 号の実証論文 13 本（オープンアクセス）の主要データ 23 件。カタログを固定したあとの独立検証に使った論文です。抽出は `scout.py` と同じ処理（step2）、表は `scout.py` と同じ関数で作成しました。

## 評価（使い方 1：論文を渡したあとのデータ抽出とカタログ照合）

同誌 2022 年第 2 巻の 4 号分から、目次順に実証論文をすべて選びました（24 本）。正解ラベルは実行前に固定しました。

| ラウンド | 論文 | 位置づけ | 誤った案内 | 抽出の一致 |
|---|---|---|---|---|
| 第 1 号 | 6 | ルール調整に使用 | 1 → 修正 | 23/27 |
| 第 2 号 | 5 | ルール調整に使用 | 1 → 修正 | 22/29 |
| **第 3・4 号** | **13** | **カタログ固定後の独立検証** | **0** | 38/50 |

第 3・4 号では、**観察された誤った案内は 0 件、論文の版まで確認できた入手経路も 0 件**でした。後者は「データが入手できない」という意味ではなく、ツールの確認能力の不足を示しています（例：工業企業データベースは、統計局ラボのホワイトリスト制度は確認できたが、論文の年をラボが提供しているかは未確認）。抽出は 1 回の実行で、結果にはばらつきがあります。詳細は [docs/access_catalog_ja.md](docs/access_catalog_ja.md)。

研究方向からの検索（使い方 2）は、この 24 本の評価には含まれていません。候補論文の選び方は別途の課題です。

## 既知の制限
- 入手経路カタログは中国のデータ 9 種のみ。デモの主要データ 23 件中 19 件はカタログ未収録
- 公式ページは変わる。結論は確認日時点のもの
- スキャン画像の PDF は読めない。出版社が自動ダウンロードを拒否することが多い
