# EconData Scout（日本語 README）

経済学の論文が**実際に使った主要データ**を、原文の引用とページ付きで示し、そのデータを**どこから・どんな条件で入手できるか**の手がかりを日本語の表にまとめるツールです。研究テーマを決める前に、「先行研究のデータを自分も使えるか」を確認する段階を想定しています。

英語版：[README.md](README.md)　｜　設計と評価：[docs/access_catalog_ja.md](docs/access_catalog_ja.md)　｜　概要：[docs/overview_ja.md](docs/overview_ja.md)

## 2 つの使い方（同じツールの 2 つの入口）

### 1. 論文を持っている場合：PDF をアップロード（主な使い方）

研究方向を指定せず、手元の論文 PDF だけを渡します。論文検索は行いません。

```bash
python scout.py --pdf paper1.pdf paper2.pdf
python scout.py --pdf papers/          # フォルダを渡すと、中の PDF をすべて調べる
```

例：
```bash
python scout.py --pdf Vertical_integration_COVID.pdf
```
→ `runs/<日時>/` に次の 2 つが保存されます。
- `report.md`：論文が使ったデータ、原文の引用とページ、サンプル年、論文に書かれた入手条件（英語）
- `access_table_ja.md`：主要データごとの日本語の表（論文が使ったデータ／結論／入口／次にやること／未確認の条件）

```
| 論文 | 論文が使ったデータ | 結論 | 入口 | 次にやること | 未確認の条件 |
| … | CSMAR（…） | 🔐 契約が必要（範囲は要確認） | https://data.csmar.com/ | 大学図書館が CSMAR を契約しているか、必要なサブデータベースと年が範囲に入っているか確認する | 所属大学の契約状況と範囲 |
```

必要なキー：`GEMINI_API_KEY`（データ抽出）。

### 2. まだ論文がない場合：研究方向から候補論文を探す → 自分で選んで入手 → 使い方 1 でアップロード

研究方向（英語）を入力すると、OpenAlex で候補論文を検索し、モデルが関連度を採点して、**候補論文の一覧と入手先**を日本語で出します。この段階では論文のダウンロードも分析もしません。

```bash
python scout.py "the effect of minimum wage on employment in China" --search-only
```
→ `runs/<日時>/candidates_ja.md`：各論文のタイトル、著者・年・掲載誌、関連度（モデルの判断）とその理由、無料の全文 PDF のリンク（OpenAlex の記録による）または論文ページ。
- **対象地域**：研究方向に「in 地域」（例：in China）があれば、対象地域が一致する論文を先に並べ、異なる可能性がある論文には ⚠ を付けます（対象地域はタイトルと要旨からのモデルの判断）。
- **データの手がかり**：要旨にカタログ収録データ（9 種）が出てくれば、その入手条件を示します（例：CGSS → 申請制）。要旨は本文ではないので「本文では未確認」と明記します。保存済みの検索結果 111 本で試すと、手がかりが出たのは 5 本でした（要旨がない論文やデータ名を書かない要旨が多いため）。出力例：[demo/outputs/candidates_ja_example.md](demo/outputs/candidates_ja_example.md)

次に、**関連度は自分で確認**し、テーマに合う論文の PDF を（大学の契約なども使って）入手して 1 つのフォルダに入れ、使い方 1 でアップロードします。一覧の最後にも、そのまま実行できるコマンドを載せています。
```bash
python scout.py --pdf papers/
```
このように「探す」と「データを調べる」を分けているのは、関連度の判断を学生が行い、分析は評価済みの使い方 1 に任せるためです。

必要なキー：`GEMINI_API_KEY`、`OPENALEX_API_KEY`（無料）。

参考：`--search-only` を付けずに `python scout.py "研究方向"` とすると、従来どおり関連度が高く無料で読める論文（3 本程度）を自動でダウンロードして調べます。この自動選択は評価していません。

### オプション（両方の使い方で共通）
- `--official`：データごとに提供機関の公式サイトを検索して現在の入手方法を確認する（`DEEPSEEK_API_KEY` が必要、有料）
- `--agent`：未確認のデータについて、論文本文を再検索するエージェントを動かす

## インストール

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
export GEMINI_API_KEY='…'      # キーは環境変数からだけ読み、ファイルには保存しません
```

Python 3.14（macOS）で動作確認。標準テストは Python 3.10（Linux）でも通過。

## 入手経路の表の読み方

表は、テーマを決める学生が知りたい順に並べています：**入手にどんな条件があるか → 次に誰に何を確認するか → まだ分からないこと**。

| 欄 | 書くこと | 例（CSMAR） |
|---|---|---|
| 結論（入手の条件と理由） | 証拠で確認できた入手の条件と、その理由 | 🔐 機関契約による制限：商用データベース、大学図書館の契約が必要 |
| 入口 | 確認した公式ページ（何のページかを明記） | CSMAR 公式サイト |
| 次にやること | 誰に何を確認するか | 本校図書館に、必要なサブデータベースと年が契約に含まれているか確認する |
| 未確認の条件 | 論文が使った版・年が入っているか、など | 論文が使ったサブデータベースと年が本校の契約に含まれるか |

結論の記号：📖 既知の経路（公開・出版物）／🔐 制限あり（登録・申請・機関契約・現地利用）／⛔ 研究者向けの公開なし／✅ 論文の版まで入口を確認済み／🔎 手がかりのみ／— カタログ未収録。
「機関の資格が必要」と分かること自体が、テーマを決める前の判断材料になります。申請が承認されるかどうかは別の問題です。

## 評価（使い方 1：論文を渡したあとのデータ抽出とカタログ照合）

同誌 2022 年第 2 巻の 4 号分から、目次順に実証論文をすべて選びました（24 本）。正解ラベルは実行前に固定しました。

| ラウンド | 論文 | 位置づけ | 誤った案内 | 抽出の一致 |
|---|---|---|---|---|
| 第 1 号 | 6 | ルール調整に使用 | 1 → 修正 | 23/27 |
| 第 2 号 | 5 | ルール調整に使用 | 1 → 修正 | 22/29 |
| **第 3・4 号** | **13** | **カタログ固定後の独立検証** | **0** | 38/50 |

第 3・4 号（独立検証）でカタログが照合した 12 件の内訳：
- **入手の条件と具体的な次の行動を示した：11 件**（工業企業データベース 4：統計局ラボは機関登録・申請承認後の現地利用／中国城市統計年鑑 4：紙の年鑑・図書館・CNKI／CSMAR 2：機関契約による制限／中国統計年鑑 1：オンライン公開）。既知の入手条件と次の行動を示すことが、この版で実現した成果です。
- **学生がデータ入手の可否を判断する助けになるか（保存結果の事後確認）：達成 7／12 件**。基準は 3 つすべて：①入手の条件に証拠がある（結論が証拠を超えない）、②次に誰に何を確認するかが明確、③残る不確実性（版・年・入口）が書かれている。内訳：工業企業データベース 4/4、CSMAR 2/2、中国統計年鑑 1/1、中国城市統計年鑑 0/4（初回：「図書館・CNKI で閲覧」に証拠がなかった）、手がかり 0/1（入手条件を示せていない）。カタログ未収録の 27 件を含めた全 39 件では 7/39。（同じ保存結果で城市統計年鑑の表示を修正した後の再確認：**11／12 件**。修正は結論を証拠に合わせたもの〔出版情報は 2016 年版のみ確認、所蔵と購入窓口は未確認〕で、論文が使った年版の入手入口は引き続き未確認。未達は 1% 人口抽出調査の手がかり 1 件）この評価は実行前に固定した基準ではなく、保存結果に対する事後の確認です（詳細：[docs/access_catalog_ja.md](docs/access_catalog_ja.md)）。
- 論文が使った版まで確認できた入手入口：0 件（版の確認は「未確認の条件」に記載。例：工業企業データベースは、ラボの制度は確認できたが、論文の年をラボが提供しているかは未確認）
- 観察された誤った案内：0 件
- 手がかりのみ：1 件

抽出は 1 回の実行で、結果にはばらつきがあります。詳細は [docs/access_catalog_ja.md](docs/access_catalog_ja.md)。

**公式サイト確認エージェント（`--official`）**：第 3・4 号でカタログにない主要データ 18 件のうち、基準を満たす結論は 6 件（誤り 0、論文の版・年まで確認 5 件）。主要データ 23 件の合計は、カタログだけの 3/23 から、学生の立場での事後確認で 16/23 になりました。エージェントが一度も確認していない検証用 16 件では 8/16（誤り 0）。入手経路の整合性チェック、総時限（240 秒）、手数切れ時の 1 回の再試行は公開版に反映済み（「ページ上で閲覧」経路は検証中）。詳細は [docs/access_catalog_ja.md](docs/access_catalog_ja.md)。

研究方向からの検索（使い方 2）は、この 24 本の評価には含まれていません。候補論文の関連度はモデルの判断なので、学生が一覧を見て選ぶ設計にしています。

## 既知の制限
- 入手経路カタログは中国のデータ 9 種のみ。デモの主要データ 23 件中 19 件はカタログ未収録
- 公式ページは変わる。結論は確認日時点のもの
- スキャン画像の PDF は読めない。出版社が自動ダウンロードを拒否することが多い
